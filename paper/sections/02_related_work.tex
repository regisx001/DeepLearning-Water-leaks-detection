\section{Related Work}
\label{sec:related}

\subsection{From Rule-Based Detection to Data-Driven Models}
Traditional leak detection in water systems has historically relied on
fixed thresholds, hydraulic rules, and manual field inspection. These
approaches are practical and interpretable, but they often miss subtle
events or trigger many false alarms under normal demand variation.

Machine learning methods improved this by learning patterns from historical
sensor data. However, shallow models usually depend on static features and
cannot fully exploit temporal dependencies that characterize leak dynamics.

\subsection{Deep Learning for Multivariate Time Series}
Deep models are now widely used for sensor anomaly detection because they
can learn temporal features directly from sequences. In this context,
convolution layers capture local changes (for example, sudden pressure drops),
while recurrent layers model longer temporal context.

Hybrid CNN-LSTM variants are especially suitable for industrial time-series
classification where both local and long-range patterns matter. For this
reason, the present work adopts a sequential CNN-BiLSTM design.

\subsection{Attention and Decision Thresholding}
Attention mechanisms help aggregate sequence information by weighting more
informative timesteps. Even with a good ranking model, the final operational
behavior depends strongly on the chosen decision threshold.

In leak detection, threshold selection is often more critical than raw AUC,
because operators may prioritize either high recall (avoid missed leaks) or
higher precision (avoid false alarms). Therefore, this paper explicitly reports
threshold sensitivity in addition to standard ROC/PR metrics.

\subsection{Position of This Work}
This project contributes a practical implementation and analysis pipeline,
not only a model architecture. It integrates data cleaning, feature engineering,
windowing, sequence modeling, calibration-based threshold selection, and
paper-ready visual reporting in one reproducible workflow.
