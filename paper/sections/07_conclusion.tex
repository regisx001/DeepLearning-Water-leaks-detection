\section{Conclusion}

In this study, we presented a deep learning approach for automatic water leak detection
in urban distribution networks using multivariate time-series sensor data. Our 1D-CNN
model, combined with sliding window transformation, feature normalization, and class
balancing, achieves \textbf{71.30\% accuracy}, \textbf{74.07\% precision}, and
\textbf{85.71\% recall} under rigorous sensor-wise cross-validation with no data leakage.

The key contributions of this work are:
\begin{enumerate}[noitemsep]
    \item A \textbf{complete, reproducible pipeline} from raw sensor data to leak
    classification, including data exploration, windowing, normalization, model training,
    and cross-validated evaluation.
    \item A \textbf{rigorous evaluation protocol} using sensor-wise GroupKFold
    cross-validation that prevents data leakage---a common pitfall that can inflate
    reported metrics by 20--30 percentage points.
    \item A \textbf{detailed analysis of methodological challenges} specific to
    small-scale sensor datasets, including label amplification, overlap-induced
    redundancy, and sensor-specific variability.
    \item \textbf{Practical handling} of severe class imbalance through balanced class
    weighting and appropriate metric selection.
\end{enumerate}

\subsection{Limitations}

\begin{itemize}[noitemsep]
    \item The dataset is relatively small (1{,}000 observations, 10 sensors, 19 leak
    events), severely limiting training data and evaluation stability.
    \item Each cross-validation fold contains only \textasciitilde21 windows, making
    metrics sensitive to individual predictions.
    \item The sliding window labeling amplifies the leak class from 1.9\% to 64.8\%.
    \item The model has been evaluated only on this specific dataset; real-world
    deployment requires validation on larger, multi-site networks.
\end{itemize}

\subsection{Future Work}

\begin{itemize}[noitemsep]
    \item \textbf{LSTM and GRU models}: Hybrid CNN-LSTM architectures combining local
    pattern extraction with sequential modeling are a particularly promising direction.
    \item \textbf{Larger and more diverse datasets}: Publicly available benchmarks such
    as the BattLeDIM challenge data could enable more robust validation.
    \item \textbf{Feature engineering}: Adding rolling statistics (moving averages,
    first-order derivatives) as additional input channels could provide complementary
    information.
    \item \textbf{Alternative labeling strategies}: Majority-vote or center-label
    strategies could reduce label amplification and produce more balanced window
    distributions.
    \item \textbf{Multi-task learning}: Jointly predicting both leak and burst events
    could improve feature learning by leveraging shared structure between failure modes.
    \item \textbf{Real-time deployment}: Adapting the model for online streaming
    inference in SCADA systems, including handling concept drift over time.
    \item \textbf{Transfer learning}: Pre-training on one water network and fine-tuning
    on another to enable rapid deployment without large amounts of labeled data.
    \item \textbf{Explainability}: Applying Grad-CAM adapted for 1D signals to visualize
    which temporal regions and sensor channels the CNN focuses on when predicting leaks.
\end{itemize}
