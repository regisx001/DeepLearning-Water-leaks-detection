\section{Methodology}
\label{sec:methodology}

\subsection{Problem Formulation}
Leak detection is formulated as binary classification on multivariate temporal
windows. For each sample window $X \in \mathbb{R}^{W \times d}$, the model
predicts the leak probability $\hat{y} \in [0,1]$, where $W=20$ timesteps and
$d=6$ features. A binary decision is produced by thresholding at $\tau$:
$\hat{y}_{\text{class}} = \mathbf{1}[\hat{y} \geq \tau]$.

\subsection{Model Architecture}
The implemented network follows a compact four-stage sequence stack totalling
\textbf{23{,}778 trainable parameters}:

\begin{enumerate}[leftmargin=*, label=\arabic*.]
\item \textbf{Multi-scale CNN encoder.} Two Conv1D blocks with batch
normalisation and ReLU activation extract local temporal patterns at
complementary receptive-field scales: Conv1D(32 filters, kernel=3) followed
by Conv1D(32 filters, kernel=5), each with \textsc{same} padding.
Dropout($p=0.30$) follows the second block.
\item \textbf{Bidirectional LSTM.} A Bidirectional LSTM with 32 units per
direction (64-dimensional hidden state, 16{,}640 parameters) encodes
temporal context in both the forward and backward directions, enabling the
model to exploit pressure build-up before and hydraulic recovery after a
leak event.
\item \textbf{Temporal self-attention.} A Dense(1) scoring layer computes
per-timestep importance logits; a Softmax normalises them into attention
weights $\{\alpha_t\}_{t=1}^{W}$; and a weighted sum (Lambda layer) produces
the 64-dimensional context vector $\mathbf{c} = \sum_t \alpha_t \mathbf{h}_t$.
The weights $\{\alpha_t\}$ are directly interpretable as anomaly-relevance
scores without additional tooling.
\item \textbf{Classification head.} Dense(16, ReLU) followed by
Dropout($p=0.40$) and a sigmoid Dense(1) output neuron producing $\hat{y}$.
\end{enumerate}

\subsection{Training Protocol}
Training is performed using \textbf{binary cross-entropy} loss and the
\textbf{Adam} optimiser (initial learning rate $\eta_0 = 5\times10^{-4}$,
batch size 32, up to 150 epochs). All random seeds are fixed at 42 for
reproducibility (TensorFlow 2.21.0). The training procedure includes:

\begin{itemize}[leftmargin=*]
\item \textbf{EarlyStopping}: monitors calibration AUC-PR with patience 25
epochs; best weights are automatically restored.
\item \textbf{ReduceLROnPlateau}: halves $\eta$ when calibration AUC-PR
stagnates for 8 consecutive epochs (floor $\eta_{\min}=10^{-6}$). The
learning rate was reduced at epoch~42 ($\eta \to 2.5\times10^{-4}$).
\item \textbf{ModelCheckpoint}: saves the state achieving the highest
observed calibration AUC-PR (best: 0.9624).
\item Feature standardisation fitted on the fit set only, applied
identically to calibration and test data.
\end{itemize}

\subsection{Threshold Selection and Evaluation}
The model outputs continuous probabilities; final class decisions depend on
the decision threshold $\tau$. Rather than defaulting to $\tau=0.5$, the
operating threshold is selected from the calibration set by maximising the
Leak $F_1$ score:
\[
\tau^{*} = \arg\max_{\tau}\;
\frac{2 \cdot \text{Pr}(\tau) \cdot \text{Re}(\tau)}
     {\text{Pr}(\tau) + \text{Re}(\tau)}
\]
yielding $\tau^{*} = 0.0200$, which is then applied unchanged to the test set.
Evaluation on test data reports:
\begin{itemize}[leftmargin=*]
\item \textbf{Ranking metrics}: AUC-ROC and AUC-PR (threshold-invariant).
\item \textbf{Operating-point metrics}: precision, recall, F1-score (Leak
class), and accuracy at $\tau^{*}$.
\item \textbf{Diagnostics}: confusion matrix, score distribution, and
threshold-sensitivity sweep.
\end{itemize}
