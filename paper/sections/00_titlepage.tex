    % Abstract
    \begin{leftbar}
        \textbf{\textcolor{headingblue}{ABSTRACT}} Water losses due to leaks in urban
        distribution networks represent a critical global challenge, causing significant
        economic losses and resource waste. Traditional leak detection methods based on
        manual inspection and threshold-based rules are often insufficient, as leaks
        produce subtle, temporally distributed deviations in sensor readings rather than
        sharp, easily detectable anomalies. In this study, we propose a deep learning
        pipeline for automatic water leak detection using multivariate time-series data
        collected from pressure and flow rate sensors deployed across ten monitoring
        nodes. We transform the raw sensor data into per-sensor sliding windows and train
        a hybrid \textbf{CNN-BiLSTM architecture augmented with a Self-Attention mechanism}.
        The convolutional block extracts local temporal patterns, the Bidirectional LSTM
        captures long-range sequential dependencies, and the attention layer assigns
        interpretable importance weights to individual timesteps. To address the severe
        class imbalance (1.9\% leak rate), we apply \textbf{Focal Loss} with a focusing
        parameter $\gamma = 2.0$ combined with decision threshold tuning on the validation
        set. In addition, three engineered features --- pressure delta, per-sensor flow
        Z-score, and pressure-flow ratio --- are introduced to enhance class separability
        beyond raw sensor readings. The model is evaluated on a held-out test set using
        F1-score, AUC-ROC, and precision-recall analysis, providing a rigorous and
        reproducible baseline for deep learning-based leak detection.
    \end{leftbar}
