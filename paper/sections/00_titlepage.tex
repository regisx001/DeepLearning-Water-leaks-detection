% Abstract
\begin{leftbar}
\textbf{\textcolor{headingblue}{ABSTRACT}} This paper presents an end-to-end
deep learning framework for automatic leak detection in urban water distribution
networks using multivariate sensor time series. The dataset consists of 5{,}590
samples collected from ten sensors over a three-week monitoring period, including
774 labelled leak events (13.8\,\%). The proposed pipeline integrates domain-informed
feature engineering, sliding-window sequence construction ($W=20$, $S=5$), and
a temporal train/calibration/test split to prevent data leakage.

We propose a hybrid deep learning architecture combining Convolutional Neural
Networks (CNN), Bidirectional Long Short-Term Memory (BiLSTM), and a self-attention
mechanism. The CNN layers capture local temporal patterns, the BiLSTM models
long-range bidirectional dependencies, and the attention mechanism highlights
the most informative time steps. The model is trained using binary cross-entropy
and evaluated with imbalance-aware metrics, including AUC-PR and calibrated
decision thresholds.

Experimental results demonstrate strong performance, achieving AUC-ROC $= 0.9412$
and AUC-PR $= 0.9583$. At the selected operating threshold $\tau = 0.0333$, the
model attains precision $= 0.9647$, recall $= 0.9011$, and F1-score $= 0.9318$,
while maintaining a low false alarm rate of $0.0231$. These results highlight
a well-balanced trade-off between detection sensitivity and false alarms,
indicating that the proposed approach is suitable for reliable deployment in
real-world smart water monitoring systems.
\end{leftbar}
