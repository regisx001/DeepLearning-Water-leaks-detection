    % Abstract
    \begin{leftbar}
        \textbf{\textcolor{headingblue}{ABSTRACT}} This paper presents an end-to-end
        deep learning pipeline for automatic leak detection in urban water distribution
        networks using multivariate sensor time series. The workflow includes
        feature engineering, per-sensor sliding-window construction, temporal train/test
        separation, and supervised sequence modeling with a compact CNN-BiLSTM-attention
        architecture. The final model is trained with binary cross-entropy and evaluated
        using a calibration-derived operating threshold.

        The test set contains 39 windows (11 leak, 28 normal). At the selected threshold
        $\tau = 0.0913$, the system achieves AUC-ROC $= 0.6364$ and AUC-PR $= 0.5008$.
        The operating point is recall-oriented, reaching leak recall $= 1.0000$ with
        leak precision $= 0.2821$, leak F1-score $= 0.4400$, and overall accuracy
        $= 0.2821$. Although this threshold triggers many false positives, it guarantees
        no missed leaks on the evaluated test split, which is often preferable in
        safety-critical monitoring. The generated visual analysis (distribution plots,
        training curves, confusion matrices, PR/ROC, score distribution, and threshold
        sensitivity) is used to characterize trade-offs and guide deployment decisions.
    \end{leftbar}
